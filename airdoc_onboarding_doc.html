📄 Manual do utilizador do sistema AirDoc

Inovare Soluções e Sistemas

O AirDoc é uma aplicação web desenvolvida pela Inovare Soluções e Sistemas para receber documentos fiscais de diversas origens, vincular com pedido de compras, validar informações relevantes, transformar para estrutura que o ERP do cliente aceite e integrar esses dados para automatizar entrada no ERP.

Essa página tem objetivo de descrever as principais funcionalidades do produto.

🔑 Acesso ao Sistema

O acesso ao sistema se dará pela URL abaixo, devendo preencher um usuário e senha válidas para acessar os dados da organização a qual o utilizador faz parte.

🌐 URL de Acesso: https://airdoc.inovarebr.com/

✨ Principais Funcionalidades

📥 Recebimento de Documentos

O AirDoc recebe documentos fiscais de diversas origens automaticamente, centralizando o processamento.

🔗 Vinculação com Pedidos

Vincula automaticamente os documentos fiscais com os pedidos de compras cadastrados no sistema.

✅ Validação de Informações

Valida informações relevantes dos documentos antes da integração com o ERP.

🔄 Transformação de Dados

Transforma a estrutura dos dados para o formato aceito pelo ERP do cliente.

⚡ Integração Automatizada

Integra os dados processados diretamente no ERP, automatizando o processo de entrada.

📞 Suporte: Para dúvidas ou problemas técnicos, entre em contato com o suporte da Inovare Soluções e Sistemas.
